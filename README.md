# Oceanic Next para lich

Tema lich (app + terminal) com a paleta [Oceanic Next](https://github.com/mhartington/oceanic-next) de Mike Hartington.

Inclui também a seção `syntax`, que o `lich native` usa para colorir código nas
telas de diff e arquivos, portada do tema oficial
[mhartington/vscode-oceanicnext](https://github.com/mhartington/vscode-oceanicnext).

## Instalar

Settings › Appearance › Import, cole a URL do repositório e clique em **Install**.

```
https://github.com/lichdotdev/oceanic-next-lich
```

## Atualizar

Settings › Appearance › **Update** na linha do tema.
